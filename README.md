# NPI-Q Summary Tool

A web-based tool designed for rapid scoring and summarization of the Neuropsychiatric Inventory Questionnaire (NPI-Q) in clinical settings.

🔗 Live site: https://cscins3.github.io/npiq-summary/

---

## 🧠 Background

The NPI-Q is widely used to assess behavioral and psychological symptoms in dementia (BPSD).  
However, in busy clinical practice, calculating total scores and summarizing results can be time-consuming and error-prone.

This tool was created to streamline the scoring process and make NPI-Q assessment faster, clearer, and more practical at the bedside.

---

## ✨ Features

- Simple web interface
- Automatic calculation of:
  - Symptom presence
  - Severity score (0–3)
  - Caregiver distress score (0–5)
- Instant summary for clinical documentation
- Works on desktop, tablet, and mobile

---

## 🎯 Purpose

To transform routine clinical assessment into a more efficient, reproducible, and digital workflow.
